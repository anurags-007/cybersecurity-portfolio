# MAL: Researching – Notes

## What is a Checksum?

A **checksum (or hash)** is a fixed-length value generated by applying a mathematical algorithm to data (such as a file).

### Uses
- Uniquely identify a file.
- Verify data integrity.

### Key Points
- Same content + same algorithm = same hash.
- Different content = different hash.
- Output length remains the same regardless of file size.

### Example

| File | Size | Example Hash |
|------|------|-------------|
| My_Video.mp4 | 4 GB | 3ABCFD456A |
| My_Selfie.png | 10 MB | 1B2Q34AAB4 |

Even though file sizes are different, hash output length remains the same.

---

## Important Hash Properties

### 1. Same Content + Same Algorithm = Same Hash

```text
File 1: "TryHackMe"
File 2: "TryHackMe"

MD5:
ABC123
ABC123
```

### 2. Same Content + Different Algorithms = Different Hashes

```text
Content: "TryHackMe"

MD5     -> A1B2C3
SHA256  -> F8E7D6C5A4...
```

Different algorithms use different mathematical operations.

### 3. Avalanche Effect

A tiny change in content completely changes the hash.

```text
File 1: "TryHackMe"
File 2: "TryHackeM"
```

---

## Uses of Checksums

### Data Integrity Check

When downloading files from the internet:

- Websites often provide MD5/SHA256 hashes.
- Compare the downloaded file hash with the official hash.

Results:

- Hash same → File downloaded correctly.
- Hash different → File may be corrupted or tampered.

### Malware Analysis

Hashes are used to identify malware samples.

Example:

```text
MD5: 44d85EAB348202F1P0X88
```

Analysts can quickly identify malware using hashes.

---

## Hash Collision

Normally:

```text
Different File -> Different Hash
```

Rarely:

```text
Different File A -> ABC123
Different File B -> ABC123
```

This is called a **Hash Collision**.

Because of collision issues, old algorithms such as **MD5** and **SHA1** are no longer considered secure. Modern systems prefer **SHA-256** and **SHA-512**.

# Sandboxing

Sandboxing is a security technique in which a program is executed in an isolated environment so that it cannot directly affect the rest of the system.

> Sandbox = A safe, isolated environment used to test suspicious or malicious files.

---

## Real-life Example

```text
Windows (Host OS)
        ↑
   VirtualBox
        ↑
Kali Linux (Guest OS)
```

Kali Linux runs inside an isolated virtual machine.

---

## Is a Virtual Machine 100% Safe?

No.

Sophisticated malware can sometimes:

- Detect virtual machines.
- Escape from virtual machines.

This is known as **VM Escape**.

Example:

- CVE-2018-2689 (VirtualBox VM Escape vulnerability)

---

# Online Sandboxing

An online sandbox is a cloud-based sandbox environment provided over the internet.

Popular services:

1. ANY.RUN
2. Hybrid Analysis

Users upload suspicious files and the service executes them securely and generates reports.

---

## Advantages of Online Sandboxing

1. Safe Analysis
   - No need to run malware on your own system.

2. Automatic Reports
   - Malware behavior is analyzed automatically.

3. Beginner Friendly
   - Useful for students and hobbyists.

---

## What Can Online Sandboxes Detect?

### 1. DNS Requests

Shows which domains the malware communicates with.

Example:

```text
malware -> evil-domain.com
```

### 2. Registry Changes

Detects changes made to the Windows Registry.

### 3. File Operations

- Files created
- Files modified
- Files deleted

### 4. Process Creation

Shows new processes started by malware.

```text
malware.exe
      ↓
powershell.exe
```

### 5. Persistence Mechanisms

How malware survives after system restart.

Examples:

- Startup Folder Entries
- Registry Run Keys
- Scheduled Tasks

---

# Quick Revision

- Checksum = Digital fingerprint of a file.
- Same content + same algorithm = Same hash.
- Output length is fixed.
- Hashes verify integrity and identify malware.
- Hash collisions are rare but possible.
- Sandbox = Isolated environment.
- Online sandbox = Cloud-based malware analysis environment.
